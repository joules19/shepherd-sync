# WhatsApp Template for Member Invite

## Template:
```
Hi {{FIRST_NAME}}! 👋

🏛 You've been invited to join *{{CHURCH_NAME}}* on Shepherd Sync!

Complete your profile to:
✅ Access events
✅ Give online
✅ Stay connected

*Get Started:*
{{INVITE_URL}}

*Or enter code in app:*
`{{INVITE_CODE}}`

⏰ _Expires: {{EXPIRATION_DATE}}_

Questions? Reply to this message!

- {{CHURCH_NAME}}
```

## WhatsApp Business API Implementation:
```typescript
await whatsappClient.sendMessage({
  to: member.phone,
  type: 'text',
  text: {
    body: `Hi ${member.firstName}! 👋\n\n🏛 You've been invited to join *${churchName}* on Shepherd Sync!\n\nComplete your profile to:\n✅ Access events\n✅ Give online\n✅ Stay connected\n\n*Get Started:*\n${inviteUrl}\n\n*Or enter code in app:*\n\`${inviteCode}\`\n\n⏰ _Expires: ${formattedExpirationDate}_\n\nQuestions? Reply to this message!\n\n- ${churchName}`
  }
});
```

## Best Practices:
1. ✅ Use WhatsApp formatting (*, _, `)
2. ✅ Include both link AND code
3. ✅ Emojis are great on WhatsApp (use tastefully)
4. ✅ Enable two-way messaging (they can reply)
5. ✅ Use WhatsApp Business API template for official messages
6. ✅ Button-based templates have higher engagement
